# Brclio Shot

[![CI](https://github.com/Brclio/brclio-shot/actions/workflows/ci.yml/badge.svg)](https://github.com/Brclio/brclio-shot/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-252933.svg)](LICENSE)

为 macOS 与 Windows 打造的键盘优先、本地优先截图工具。区域、窗口、当前屏幕、延时、跨应用手动滚动长截图和网页整页截图，都从一个安静的工作台开始。

> 当前版本：`v0.1.0`。仓库处于首个可用版本阶段；下载未受平台信任的开发构建前，请先阅读[签名与发布说明](docs/RELEASING.md)。

## 运行环境

| 系统 | 支持范围 | Release 架构 |
| --- | --- | --- |
| macOS | macOS 13 或更高版本 | Apple Silicon（arm64）与 Intel（x64） |
| Windows | 64 位 Windows 10 / 11 | x64 |

Linux 暂不在支持范围内。

## 功能

| 能力 | 当前实现 |
| --- | --- |
| 区域截图 | 冻结光标所在显示器，拖拽框选；提供像素放大镜、尺寸/坐标读数、移动、缩放与键盘微调 |
| 窗口截图 | 读取可捕获窗口的本机预览列表，支持搜索、刷新后选择；不会上传窗口标题或预览 |
| 当前屏幕 | 捕获光标所在显示器，而不是一次合并全部显示器 |
| 延时截图 | 工作台可选 3、5、10 秒；全局快捷键默认使用 5 秒，倒计时后进入区域选择 |
| 跨应用长截图 | 选定屏幕区域后，由用户在目标应用中手动向下滚动；本机采样、检测重叠与固定边缘并拼接 |
| 网页整页截图 | 输入 HTTP/HTTPS 地址，在临时隔离会话中加载并分片生成长图；不复用浏览器登录态 |
| 编辑器 | 裁剪、矩形、椭圆、箭头、直线、画笔、荧光笔、文字、序号、马赛克、颜色/粗细、撤销/重做与缩放 |
| 贴图 | 将编辑结果置顶显示，支持缩放、透明度、复制与另存 |
| 本地历史 | 保存本机缩略图与原图，支持搜索、重开、删除、清空；可在设置中关闭 |
| 保存 | 自定义目录、PNG/JPEG/WebP、JPEG 质量、文件名模板；默认目录为“图片/Brclio Shot” |
| 捕获后动作 | 进入编辑器、复制到剪贴板或直接保存；直接保存后可选继续复制 |
| 桌面体验 | 托盘菜单、开机启动、系统/浅色/深色主题、可修改的全局快捷键与冲突提示 |

## 默认全局快捷键

所有全局快捷键都可以在“偏好设置 → 全局快捷键”中修改。系统或其他应用占用组合键时，工作台会显示注册失败原因，托盘与工作台入口仍可使用。

| 操作 | macOS | Windows |
| --- | --- | --- |
| 打开截图工作台 | `⌥ ⇧ S` | `Ctrl + Shift + S` |
| 区域截图 | `⌥ ⇧ A` | `Ctrl + Shift + A` |
| 窗口截图入口 | `⌥ ⇧ W` | `Ctrl + Shift + W` |
| 当前屏幕 | `⌥ ⇧ F` | `Ctrl + Shift + F` |
| 长截图 | `⌥ ⇧ L` | `Ctrl + Shift + L` |
| 5 秒延时截图 | `⌥ ⇧ D` | `Ctrl + Shift + D` |
| 重复上一区域 | `⌥ ⇧ R` | `Ctrl + Shift + R` |
| 打开历史 | `⌥ ⇧ H` | `Ctrl + Shift + H` |
| 完成长截图 | `⌘ ⇧ Enter` | `Ctrl + Shift + Enter` |

`窗口截图入口`会打开工作台，随后从窗口来源列表中选择目标。v0.1 不会在外部窗口上悬停描边，也不会仅凭光标位置直接抓取某个外部窗口。

工作台首页还支持数字键 `1`–`6` 启动对应截图方式。选区中可用 `Enter` 完成、`Esc` 取消、方向键移动 1 像素、`Shift + 方向键` 移动 10 像素；编辑器快捷键见[使用指南](docs/USER_GUIDE.md#编辑器快捷键)。

## 正确完成长截图

跨应用长截图不会代替用户向目标应用发送滚轮事件。请按以下方式操作：

1. 将目标内容放到光标所在显示器，启动“长截图”。
2. 框选内容滚动区域，尽量避开滚动条、持续动画、视频和会不断变化的悬浮控件；选区至少为 80 × 80 像素。
3. 回到目标应用，沿同一方向缓慢向下滚动。默认每 650 毫秒采样一次，建议每次移动不超过选区高度的一半，并保留清晰重叠内容。
4. 到达结尾后，点击浮动控制条的“完成”，或按“完成长截图”全局快捷键。
5. 等待重叠分析和拼接。若提示置信度不足，回退到有共同内容的位置，减慢滚动速度后重试。

固定页头/页脚会被尽量识别，但复杂动画、虚拟列表、横向位移、突然跳页或双向滚动仍可能导致拼接失败。普通应用请使用手动滚动长截图；公开网页也可以尝试“网页整页”，两者的安全边界与限制不同。

## 权限与隐私

- macOS 首次截图需要“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”权限。授权后如状态未刷新，请完全退出并重新打开 Brclio Shot。
- Windows 通常不需要单独的屏幕录制授权；受保护内容、DRM 视频和部分系统窗口仍可能返回黑屏或不可捕获。
- 区域/窗口/屏幕捕获、编辑、拼接、历史和保存均在本机完成；应用没有遥测、账号或截图上传服务。
- “网页整页”必须访问用户输入的网址，因此远端网站仍能看到正常网络请求信息；该功能不是匿名浏览器。它使用一次性隔离分区，拒绝页面权限、下载和新窗口，不共享日常浏览器 Cookie。
- 历史默认保存在 Electron 的应用数据目录；将“最多保留历史”设为 0 可关闭后续历史写入。清空历史不会删除已经保存到自选目录的图片。

更多操作和排障步骤见[使用指南](docs/USER_GUIDE.md)，更完整的信任边界见[安全说明](docs/SECURITY.md)。

## 开发、测试与构建

需要 Node.js `22.12+`（或 Node.js 24 LTS）与 npm。桌面安装包应在目标系统上构建。

```bash
git clone git@github.com:Brclio/brclio-shot.git
cd brclio-shot
npm ci
npm run dev
```

提交前验证：

```bash
npm run typecheck
npm test
npm run build
```

本机构建安装包：

```bash
npm run package:mac   # 在 macOS 上生成 DMG 与 ZIP
npm run package:win   # 在 Windows 上生成 NSIS 与便携版
```

产物写入 `release/`。没有发布证书与公证凭据时，macOS 包只做 ad-hoc 开发签名，Windows 包保持未签名；两者都可能触发 Gatekeeper 或 SmartScreen，不能描述为受信任的正式发行版。完整流程见[发布说明](docs/RELEASING.md)。

## 架构

| 层 | 目录 | 职责与边界 |
| --- | --- | --- |
| Electron 主进程 | `src/main/` | 窗口生命周期、系统权限、桌面源、抓帧、滚动拼接、网页捕获、文件保存、历史、托盘和全局快捷键 |
| Preload 桥 | `src/preload/` | 只暴露显式、带类型的 IPC API；不向页面暴露 Node.js |
| React 渲染层 | `src/renderer/` | 工作台、选区层、编辑器、贴图和长截图控制条 |
| 共享契约 | `src/shared/` | 截图、设置、快捷键、历史和 IPC 类型/通道 |
| 单元测试 | `tests/unit/` | 捕获坐标/来源、保存、设置与滚动拼接核心逻辑 |

所有应用窗口启用上下文隔离、渲染进程沙箱与 Web Security，并关闭 Node Integration。主进程校验 IPC 发送窗口和关键输入；文件显示操作只允许应用已知的保存路径。详细开发约定见[开发文档](docs/DEVELOPMENT.md)。

## v0.1 已知限制

- 窗口捕获通过来源列表预览后选择，不提供外部窗口悬停描边。
- 跨应用长截图依赖用户手动滚动；没有自动驱动目标应用滚动，也不保证适配所有虚拟列表或动态界面。
- 网页整页使用隔离会话，不继承 Safari、Chrome、Edge 或系统登录态；登录页面请改用手动滚动长截图。
- 网页无限滚动、跨域画布、视频、DRM 内容与某些 GPU/系统窗口可能无法完整捕获。
- 单次长图受 100,000 像素高度与 200,000,000 像素总量安全上限约束；超限会停止而不是继续分配内存。
- 尚未集成自动更新、云同步、OCR、录屏或移动端版本。
- 仓库 CI/Release 支持无密钥构建；缺少平台发布密钥时，macOS 上传 ad-hoc 开发签名包，Windows 上传未签名开发包。
