# Brclio Shot 使用指南

本指南对应 `v0.1.0`。Brclio Shot 的默认原则是：尽量用键盘启动，截图数据留在本机，失败时停止并给出可理解的原因。

## 第一次启动

1. 打开 Brclio Shot，确认侧栏显示“本地服务就绪”。
2. macOS 用户点击权限提示中的“检查并授权”，在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”允许 Brclio Shot。
3. 如果授权后仍显示未允许，请完全退出应用再重新打开。权限变化由 macOS 管理，单纯关闭工作台窗口不一定会重启进程。
4. 打开“偏好设置”，确认默认保存目录和全局快捷键没有冲突。

Windows 通常无需额外授权。企业策略、远程桌面、DRM/受保护窗口和显卡驱动仍可能限制可捕获内容。

## 六种截图方式

### 1. 区域截图

启动后当前显示器会被冻结。拖动空白区域新建选区，拖动选区或按住 `Space` 移动，拖动八个控制点调整尺寸。

| 按键 | 操作 |
| --- | --- |
| `Enter` | 完成选区 |
| `Esc` | 取消 |
| `方向键` | 每次移动 1 像素 |
| `Shift + 方向键` | 每次移动 10 像素 |
| 创建时按 `Shift` | 锁定为正方形 |
| 调整控制点时按 `Shift` | 保持当前宽高比 |
| `Space` | 进入移动选区状态 |

放大镜、坐标和尺寸读数用于定位边缘。区域截图仅覆盖光标所在显示器；需要截另一块屏幕时，先将光标移过去再启动。

### 2. 窗口截图

点击“窗口截图”后，工作台读取当前可捕获窗口的缩略图和标题。使用搜索框过滤，必要时点击“刷新”，然后点选目标。

Brclio Shot 自身窗口会被过滤。当前实现不是系统窗口探测器：不会在其他应用窗口上显示悬停边框；全局窗口快捷键打开工作台，仍需在来源列表中确认目标。

### 3. 当前屏幕

直接捕获光标所在显示器。多显示器环境不会自动拼成一张横向大图。

### 4. 延时截图

工作台支持 3、5、10 秒。倒计时结束后进入区域选择，适合先展开菜单、浮层或悬停状态。全局延时快捷键固定以 5 秒启动；如需 3 或 10 秒，请从工作台选择。

### 5. 跨应用长截图

1. 先让目标应用停在长内容开头，将光标放在目标显示器。
2. 启动长截图，框选真正滚动的内容区域。选区最小为 80 × 80 像素。
3. 完成选区后切回目标应用，缓慢、持续地向下滚动。
4. 默认每 650 毫秒采样一次。每次滚动不超过选区高度一半，并短暂停留，能给重叠算法留下稳定共同内容。
5. 到达结尾后，点击控制条“完成”或按 `⌘/Ctrl + Shift + Enter`。
6. 拼接完成后按设置进入编辑器、剪贴板或保存目录。

为了减少错缝：

- 只向一个方向滚动；不要突然回到顶部或横向移动。
- 尽量避开视频、轮播、骨架屏、闪烁光标和不断变化的数字。
- 固定页头/页脚会被尝试识别，但大型悬浮层仍可能干扰。
- 虚拟列表会回收已经离屏的 DOM/视图，内容重复时容易造成歧义；请缩短每次滚动距离。
- 提示“重叠区域置信度不足”时，回退到上一屏仍可见的位置，滚得更慢再试。

该模式不会自动控制第三方应用的滚轮或滚动条，临时帧只在当前捕获过程中用于本机拼接。默认最多采样 80 帧，可在设置中调整。

### 6. 网页整页截图

输入 `http://` 或 `https://` 地址。Brclio Shot 会创建一个隐藏、临时、隔离的网页窗口，触发懒加载后按瓦片捕获整页。

- 不使用 Safari、Chrome 或 Edge 的 Cookie 与登录态。
- 页面权限请求、新窗口和下载会被拒绝。
- 目标网站仍会收到正常网络请求，看到你的网络地址与客户端特征。
- 登录后页面、无限滚动、视频、跨域画布和受保护媒体可能不完整；此时改用跨应用手动长截图。
- 宽度、高度或总像素超过安全上限时会中止。

## 默认全局快捷键

| 操作 | macOS | Windows |
| --- | --- | --- |
| 打开工作台 | `⌥ ⇧ S` | `Ctrl + Shift + S` |
| 区域截图 | `⌥ ⇧ A` | `Ctrl + Shift + A` |
| 窗口截图入口 | `⌥ ⇧ W` | `Ctrl + Shift + W` |
| 当前屏幕 | `⌥ ⇧ F` | `Ctrl + Shift + F` |
| 长截图 | `⌥ ⇧ L` | `Ctrl + Shift + L` |
| 5 秒延时截图 | `⌥ ⇧ D` | `Ctrl + Shift + D` |
| 重复上一区域 | `⌥ ⇧ R` | `Ctrl + Shift + R` |
| 历史 | `⌥ ⇧ H` | `Ctrl + Shift + H` |
| 完成长截图 | `⌘ ⇧ Enter` | `Ctrl + Shift + Enter` |

修改快捷键后点击“保存设置”。相同组合键会被拒绝；被系统或其他应用占用时，该行显示未注册状态。

工作台首页在没有聚焦输入框时支持：`1` 区域、`2` 窗口、`3` 当前屏幕、`4` 长截图、`5` 延时、`6` 网页整页。

## 保存、命名与历史

默认保存目录是系统“图片”目录下的 `Brclio Shot` 文件夹。可以选择 PNG、JPEG 或 WebP；JPEG 质量范围为 40%–100%。

文件名模板支持：

| 变量 | 内容 |
| --- | --- |
| `{date}` | 本地日期，如 `2026-08-26` |
| `{time}` | 本地时间，包含毫秒 |
| `{mode}` | 区域、窗口、全屏、长截图、网页整页或延时 |
| `{timestamp}` | Unix 毫秒时间戳 |

同名文件不会静默覆盖；直接保存会追加 `-2`、`-3` 等序号。编辑器的“保存”使用默认目录，贴图窗口的“保存”会打开另存对话框。

历史是独立于导出文件的本地副本。删除或清空历史不会删除导出的图片；删除导出图片也不会自动删除历史。将历史上限设为 0 后，新截图不再进入历史。

## 贴图

编辑器中按 `⌘/Ctrl + Shift + P` 创建置顶贴图。鼠标移入显示工具栏：

- 滚轮或 `−` / `+` 调整显示比例；
- 透明度范围为 40%–100%；
- 可复制、另存或关闭；
- 拖动顶部条移动窗口，窗口缩放保持原图宽高比。

## 常见问题

### macOS 只得到黑屏

检查屏幕录制权限是否授予实际运行的 Brclio Shot。开发模式与安装后的应用可能被系统视为不同程序；修改权限后完全退出并重开。

### 快捷键没有反应

在偏好设置查看该快捷键是否显示“已启用”。若被系统、输入法、窗口管理器或其他截图工具占用，更换组合键并保存。退出应用时全局快捷键会自动注销。

### 长截图重复、断层或直接失败

减小每次滚动距离，增加重叠，等待一次采样后再继续；避免滚动方向变化和动画区域。拼接器在置信度不足时主动失败，目的是避免输出看似成功但已经错缝的图片。

### 网页整页没有登录内容

这是隔离会话的预期行为。请在常用浏览器中打开登录页面，再使用跨应用手动长截图。

### 安装包提示来源未知

发布签名密钥缺失时，macOS 产物只有 ad-hoc 开发签名，Windows 产物保持未签名，两者都不代表平台信任。不要忽略来源不明的第三方镜像；核对 GitHub Release 的 `SHA256SUMS.txt`，并阅读[发布说明](RELEASING.md)。
